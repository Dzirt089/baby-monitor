# Device-тест 0.3.0 (2 Android-устройства) — звук/reconnect/battery

> **Частично выполнен 2026-11-08** на Huawei nova Y90 + Huawei nova 13 Pro (Android 12, v0.3.1):
> pairing, слышимость (владелец подтвердил), MediaFlowing, reconnect Wi-Fi off/on, screen-off 12 с,
> Stop — PASS. Не выполнены: звонки/audio focus, Bluetooth/наушники, battery без зарядки, 8h soak,
> 100 циклов, TalkBack, camera↔camera, OEM-матрица — 007. Результаты:
> [device-test-results-2026-11-08.md](device-test-results-2026-11-08.md).

**Устройства владельца**: Huawei nova 13 Pro и Huawei nova Y90 (adb/USB-отладка использовались в прогоне 2026-11-08; часть шагов ручная).
**Цель**: подтвердить реальную слышимость Child → Parent по локальной сети, поведение при обрыве
сети/звонке/маршруте и ориентировочный расход батареи.

> **Важно**: до твоего подтверждения слышимости на двух устройствах приложение не считается
> работающей радионяней. Не публикуй APK/логи с персональными данными; скриншоты QR не нужны.

## 0. Подготовка

1. Скачать на ПК из GitHub Releases **v0.3.0**: io.github.dzirt089.babymonitor-Signed.apk и
   app-release.apk.sha256 (private repo — под аккаунтом владельца).
2. Проверить SHA-256: PowerShell `Get-FileHash .\io.github...-Signed.apk -Algorithm SHA256` —
   должен совпасть с checksum.
3. Установить APK на оба телефона (разрешить установку из неизвестных источников; Huawei:
   «Настройки → Безопасность → Установка неизвестных приложений» для файлового менеджера/браузера).
   APK одинаковый на обоих устройствах.
4. Wi-Fi: оба телефона в одной сети (проверить и 2.4 ГГц, и 5 ГГц, если роутер разделяет сети —
   нас интересует один и тот же SSID/VLAN). Интернет не обязателен для работы.
5. Huawei: отключить агрессивную оптимизацию батареи для «Радионяни» на время теста
   (Настройки → Батарея → Запуск приложений → Радионяня → управлять вручную: разрешить
   автозапуск/работу в фоне). Это условие теста; в 007 проверим поведение без whitelist.
6. Если устройства ещё не сопряжены — пройти pairing (как в v0.2.0: Child QR → Parent сканирует →
   ответный QR → одинаковый 6-значный код → подтвердить на обоих).

## A. Слышимость (главное)

- [ ] Child: «Я ребёнок» → «Перейти к мониторингу» → «Запустить мониторинг» → разрешение микрофона
      только при старте; уведомление «Радионяня: ребёнок» появилось.
- [ ] Parent: «Я родитель» → «Перейти к мониторингу» → «Запустить мониторинг» → разрешение
      уведомлений; уведомление «Радионяня: родитель».
- [ ] В течение ~10 секунд на Parent слышен звук с микрофона Child; в уведомлении/на экране
      состояние «Звук передаётся».
- [ ] Речь ребёнка/окружающий звук разборчивы на расстоянии 1–3 м; громкость Parent достаточная.
- [ ] Задержка: оценить субъективно (хлопок перед Child, слушать Parent) — записать примерную
      задержку в секундах (норма для LAN: 0.2–0.5 с).
- [ ] Child не воспроизводит звук (динамик Child молчит); Parent не запрашивает микрофон.
- [ ] 5 минут непрерывной работы: звук не пропадает, нет нарастающего эха/треска.
- [ ] Выключить экран на обоих: звук продолжается; уведомления остаются.
- [ ] Свернуть приложение (домой): звук продолжается.
- [ ] Stop в уведомлении Parent/Child: сервис останавливается, уведомление исчезает, звук
      прекращается. Повторный Start работает.

## B. Reconnect / сеть

- [ ] На Child выключить Wi-Fi на 5–10 секунд, включить: Parent должен показать
      «Переподключение…», затем снова «Звук передаётся» (авто-восстановление).
- [ ] То же, выключив Wi-Fi на Parent.
- [ ] Выключить Wi-Fi на 30–60 секунд: приложение не зависает; по истечении попыток —
      состояние «Ошибка» с понятным сообщением (без секретов); после включения Wi-Fi и
      повторного Start — работает.
- [ ] Переместиться с телефонами в дальнюю комнату/за роутер: при ухудшении сигнала возможны
      переподключения; проверить, что после стабилизации звук возвращается.
- [ ] Смена сети (другой SSID/диапазон): ожидается typed-ошибка/переподключение; записать поведение.
- [ ] Guest Wi-Fi / AP isolation (если есть): ожидается «peer недоступен/media path absent» без
      зависания сервиса.

## C. Звонки / audio focus / маршрут (Parent)

- [ ] Входящий звонок на Parent во время передачи: воспроизведение останавливается (focus loss),
      после звонка — восстановление или понятная ошибка/переподключение.
- [ ] Подключить Bluetooth-наушники на Parent: звук уходит в наушники; отключить — возвращается
      на динамик (или переподключение).
- [ ] Проводные наушники на Parent: аналогично.
- [ ] Входящий звонок на Child: микрофон может быть занят — после звонка передача
      восстанавливается; записать поведение.

## D. Батарея/стабильность

- [ ] 30–60 минут активной передачи: оценить расход батареи на Child и Parent (Настройки →
      Батарея → Радионяня: %), температуру корпуса.
- [ ] За это время: не было ли падений/ANR, пропаданий звука без восстановления.
- [ ] Проверить экран «Диагностика» на обоих: роль, состояние foreground-сессии, Media-состояние,
      доверенное устройство; без секретов/аудио.

## E. Что записать в отчёт

1. Модели/ОС: Huawei nova 13 Pro (HarmonyOS/Android версия), Huawei nova Y90 (EMUI/Android версия),
   SSID/диапазон (2.4/5 ГГц), роутер.
2. По пунктам: OK / FAIL / не проверено; при FAIL — шаги и что видно на экране.
3. Оценка задержки и качества звука, поведение при reconnect/звонке/BT.
4. Расход батареи за сеанс (время, %), температура.
5. Скриншоты экранов (без QR-кодов) и, если появится adb, logcat:
   `adb logcat -d | findstr /I "BabyMonitor AndroidRuntime"` (аудио/секретов в логах нет by design).
6. Любые падения — время, экран, шаги. При наличии adb (был доступен 2026-11-08) приложить
   `adb logcat -d` без аудио/секретов и `dumpsys audio`/`dumpsys notification` фрагменты.

## Известные ограничения 0.3.0 (не дефекты)

- ParentLossAlarm пока не подключён к media-сеансу; тревога по потере связи — следующий этап (007).
- Авто-обновлений нет (ADR-0008): новая версия — вручную с GitHub Releases.
- Полная OEM-матрица (Pixel/Samsung/Xiaomi/Huawei разных API), 8h soak, TalkBack, battery
  profiling — 007.
- Приложение не является медицинским изделием и не заменяет наблюдение взрослого.
